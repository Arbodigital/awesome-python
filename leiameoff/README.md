# Leiameoff

Base de conhecimento orientada por agentes para transformar guias de ajuda em ações práticas.

## Objetivo

Organizar, validar e transformar conteúdos oficiais e comunitários em manuais de uso, diagnósticos e rotas de resolução.

## Estrutura

- `agents/`: responsabilidades e contratos dos agentes especialistas.
- `schemas/`: formatos padrão para mapas de ações e índices de fontes.

## Fluxo padrão

1. Coleta de fontes
2. Organização por produto/tópico
3. Verificação de confiabilidade
4. Geração de guias e passos de ação
5. Curadoria contínua e atualização

## Padrão de expansão

- `leiameoffchr`: módulo Chrome
- futuros módulos: Docs, Fotos, Android, etc.
